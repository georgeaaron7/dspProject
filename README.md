# Realtime audio processing

Captures live microphone input, processes it through a multi-stage DSP pipeline, and visualizes every step in real-time using an interactive PyQtGraph GUI.

### Features: 
- Live Spectrum Analyzer
- Step-by-Step DSP Snapshot
- Logarithmic Frequency Binning
- Thread-safe audio capture

### Steps: 
1. Clone the repo
2. Create a venv and activate it
3. Install requirements
4. Run the dsp_dashboard.py file
